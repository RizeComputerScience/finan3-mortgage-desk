Check desk receipts

This page is for instructors. The desk is graded on completion: the points printed in the colored box on each receipt are the grade, and you can enter them as shown. Use this page to spot-check. Add one or more receipt files (PNG) that students uploaded; for each one, the page rebuilds that student's numbers from the desk code on the receipt and re-checks every step from scratch, without trusting the image. Receipts carry no name or email: Learn shows who uploaded each file. Two students uploading the same desk code means one copied the other's file.

Points (the assignment rubric): full points for every step verified, half for at least half the steps, 0 for fewer. Nothing leaves your computer; the files are read in this browser only.
